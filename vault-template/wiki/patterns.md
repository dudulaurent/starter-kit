# Pattern Registry

*Canonical list of vault-wide Patterns. Reviewed weekly with `lint-vault`.*
*A Pattern is added only after the owner gives an explicit yes, and the scope is confirmed first.*
*Deprecated Patterns move to the Archive section below, never deleted.*

Scopes: **Vault** (all agents), **Code** (agents that own software), **Ops** (agents with no code),
**Agent** (one agent only, not a propagation candidate).
